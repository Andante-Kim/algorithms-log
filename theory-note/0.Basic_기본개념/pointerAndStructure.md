# 포인터(Pointer)

## (1) 포인터 기초

1. 포인터: 일반적인 데이터(값)이 아닌, **메모리의 주소값**을 저장하는 변수
    * 선언 방식: `자료형 *변수명`
    * 주소 연산자(`&`): 변수의 메모리 시작 주소를 추출한다.
    * 역참조 연산자(`*`): 포인터가 가리키는 주소에 저장된 실제 값에 접근한다.
2. 포인터의 크기와 자료형: 포인터 변수의 크기는 가리키는 대상의 자료형과 관게없이 **CPU의 아키텍처**에 따라 결정된다.
    * 32bit 시스템: 포인터 크기 = 4 bytes
    * 64bit 시스템: 포인터 크기 = 8 byte
    * 자료형의 의미 : 포인터 앞의 자료형(int, char 등)은 "해당 주소부터 몇 바이트를 읽어 들일 것인가"와 "어떤 단위로 해석할 것인가"를 결정한다.
3. [코드 예시] 포인터 활용
    ```C
    int main() {
        int num = 10;      // 일반 변수 선언
        int *ptr = &num;   // 포인터 변수에 num의 주소 저장

        printf("num의 값: %d\n", num);    // 10
        printf("num의 주소: %p\n", &num);  // 메모리 주소 출력
        printf("ptr의 값: %p\n", ptr);    // &num과 동일
        printf("ptr이 가리키는 값: %d\n", *ptr); // 역참조: 10

        *ptr = 20;     // 포인터를 통해 원본 값 수정
        printf("수정 후 num: %d\n", num);  // 20

        return 0;
    }
    ```
4. 포인터 사용 시 주의할 점
    * Wild Pointer : 초기화되지 않은 포인터. 쓰레기 주소값을 가지고 있어 접근 시 프로그램이 강제 종료될 수 있다.
    * Dangling Pointer (허상 포인터) : 가리키던 메모리가 해제되었음에도 여전히 해당 주소를 가지고 있는 포인터
    * `TIP`: 포인터 변수를 선언할 때는 사용 직전까지 `NULL`로 초기화하는 습관이 필수적이다. (`int *ptr = NULL;`)
5. 포인터와 배열의 관계 : 배열의 이름은 그 자체로 **배열의 첫 번째 요소의 시작 주소**를 의미하는 상수 포인터다.
    * `arr` == `&arr[0]`
    * `*(arr + i)` == `arr[i]`
    * 배열 포인터를 이용하면 배열 전체를 함수로 전달할 때 메모리 효율을 극대화할 수 있다.

## (2) 이중 포인터와 포인터 배열

1. 이중 포인터 (Double Pointer) : 포인터 변수의 **주소값**을 저장하는 포인터. 즉, "포인터를 가리키는 포인터"이다.
    * 선언 방식: `자료형 **변수명;`
    * 작동 원리: `ptr2` -> `ptr1` -> `변수`
    * 주요 용도:
        * 함수 내부에서 외부의 포인터 값을 변경해야 할 때
        * 동적 할당된 2차원 배열을 다룰 때
2. 포인터 배열 (Array of Pointers) : 포인터 변수들을 모아놓은 배열. 배열의 각 요소가 주소값을 저장한다. 
    * 선언 방식: `자료형 *배열명[크기];`
    * 특징: 각 요소가 가리키는 대상의 크기가 달라도 상관없다.
    * 주요 용도: 문자열 배열(여러 개의 문자열)을 처리할 때 주로 사용한다.
3. [코드 예시]
    ```C
    #include <stdio.h>

    int main() {
        // 1. 이중 포인터 예시
        int num = 100;
        int *ptr = &num;     // 싱글 포인터
        int **dptr = &ptr;   // 이중 포인터

        printf("num: %d, *ptr: %d, **dptr: %d\n", num, *ptr, **dptr);
        // 결과 모두 100 출력

        // 2. 포인터 배열 예시 (문자열 관리)
        char *fruits[3] = { "Apple", "Banana", "Orange" };

        for (int i = 0; i < 3; i++) {
            printf("fruits[%d]: %s\n", i, fruits[i]);
        }

        return 0;
    }
    ```
4. 주의사항
    * 연산자 우선순위: `*p[n]`은 `*(p[n])`과 같다. 배열 연산자 (`[]`)가 역참조 연산자(`*`)가 우선순위가 높기 때문이다.
    * 동적 할당: 이중 포인터를 활용해 2차원 배열을 동적 할당할 경우, 각 행마다 별도의 `malloc`이 필요하며, 해제(`free`) 역시 역순으로 꼼꼼히 진행해야 메모리 누수를 방지할 수 있다.

# 구조체(Structure)

## (1) 구조체 기초

1. 구조체(Structure) : 서로 다른 자료형의 변수들을 하나로 묶어 사용자 정의 자료형을 만드는 도구
    * 개념: 이름, 나이, 키와 같은 서로 연관된 데이터를 하나의 단위(Person)로 관리하기 위해 사용하낟.
    * 정의 방식: `struct` 키워드를 사용한다.
2. 구조체의 선언과 접근 : 구조체를 정의한 후에는 일반 변수처럼 선언하여 사용하며, 내부 멤버에 접근할 때는 **점(`.`) 연산자**를 사용한다.
    ```C
    struct Student {
        int id;
        char name[20];
        float grade;
    };

    struct Student s1 = {202401, "Hong", 4.5}; // 선언과 초기화
    s1.grade = 4.0; // 멤버 접근 및 수정
    ```

## (2) 구조체 포인터

1. 구조체 포인터 (Pointer to Structure) : 구조체 변수의 주소를 저장하는 포인터이다. 포인터를 통해 구조체 멤버에 접근할 때는 점(`.`) 연산자 대신 **화살표(`->`) 연산자**를 사용한다는 점이 핵심이다.
    * 역참조 접근: `(*ptr).member` (괄호 필수)
    * 간접 참조 연산자: `ptr->member` (위 방식의 축약형이자 권장 방식)
4. [코드 예시]
    ```C
    #include <stdio.h>
    #include <string.h>

    struct Character {
        char name[20];
        int level;
        int hp;
    };

    // 구조체 포인터를 인자로 받는 함수
    void levelUp(struct Character *c) {
        c->level++;    // 화살표 연산자로 원본 값 수정
        c->hp += 10;
    }

    int main() {
        struct Character hero = {"Warrior", 1, 100};
        struct Character *ptr = &hero; // 구조체 포인터 선언

        // 1. 일반 접근
        printf("Name: %s, Level: %d\n", hero.name, hero.level);

        // 2. 포인터 접근 (화살표 연산자)
        ptr->hp = 120; 
        
        // 3. 함수 호출 (Call by Reference)
        levelUp(&hero);

        printf("After Level Up - Level: %d, HP: %d\n", hero.level, hero.hp);

        return 0;
    }
    ```
5. 요약 정리
    |구분|일반 구조체 변수|구조체 포인터|
    |---|---|---|
    |**선언 예시**|`struct Person p;`|`struct Person *ptr = &p;`|
    |**멤버 접근**|`p.name` (Dot 연산자)|`ptr->name` (Arrow 연산자)|
    |**메모리**|구조체 전체 크기 할당|주소값 크기(8 bytes)만 할당|
    |**효율성**|데이터 복사 시 부하 발생|주소만 전달하여 효율적임|
6. 결합의 의의
    * 구조체와 포인터를 결합하면 **연결 리스트(Linked List)**나 **트리(Tree)**와 같은 동적인 자료구조를 만들 수 있다. 각 구조체 안에 다음 구조체의 주소를 가리키는 포인터를 포함하는 포인터를 포함시켜 데이터를 체인처럼 연결하는 방식이다.
